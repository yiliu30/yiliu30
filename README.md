# Hi, I'm Yi Liu 👋

**Making AI inference faster, more accurate, and easier to understand.**

I'm an AI engineer at Intel focused on **low-bit quantization, efficient attention, and GPU kernel optimization**.

I maintain [AutoRound](https://github.com/intel/auto-round) and [LLM-Compressor](https://github.com/vllm-project/llm-compressor), contribute to open-source inference frameworks, and create interactive visualizations to explain how these systems work.

## 🔬 What I'm exploring

- **Low-bit inference:** INT4, FP8, MXFP4/MXFP8, NVFP4, and accuracy-performance tradeoffs.
- **Efficient attention:** SageAttention, block-sparse attention, and attention quantization error.
- **GPU kernels:** Performance profiling, compiler behavior, and low-level optimization.
- **Multimodal inference:** Image and video generation with efficient memory and compute.
- **AI for systems:** Agents for GPU kernel development and performance optimization.
